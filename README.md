# Microstructure Treasury Engine

A structured, operator-grade study of market microstructure integrated directly into the 90-day U.S. Treasury market.

## Folder Structure

/plates  
  /market_structure  
  /order_book  
  /execution  
  /dark_pools  
  /etf_index  
  /shareholder_register  
  /liquidity_patterns  
  /operator_synthesis  
  /treasury_integration  

Each folder contains atomic “plates” — standalone modules representing one microstructure concept and its Treasury analogue.
